Mathematical Formulation

For an independent Bernoulli process with loss probability $q = 1 - p = 0.5978$:

P(L >= k) = q^k = (0.5978)^k

Because each loss is strictly limited to -$10.84 on average, an 8-loss streak causes only -$86.72 in drawdown, readily absorbed by a single $140+ winning trade.
